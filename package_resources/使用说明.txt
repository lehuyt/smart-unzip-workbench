智能解压工作台

这是无需安装 Python 或额外 Python 库的 Windows 发布版。

使用方法：
1. 先自行安装 WinRAR 或 7-Zip。
2. 双击“智能解压工作台.exe”。
3. 将待处理的压缩文件或文件夹拖入程序，点击“开始处理”。
4. 如果程序没有自动找到解压软件，请打开“设置”手动选择 WinRAR.exe 或 7z.exe。

文件说明：
- 密码本.txt：普通密码本，可以直接编辑。
- 临时密码本.txt：按文件名或文件夹名匹配的临时密码本，可以直接编辑。
- config.json：程序配置文件，一般不需要手动修改。

分享时请将“智能解压工作台”整个文件夹一起压缩后发送，不要只发送 EXE 文件。
WinRAR 和 7-Zip 不包含在本程序中，需要使用者自行安装。
